# Phase 2: Core Features (Fields & Slots)

## Goal
Implement the core entity logic allowing owners to manage fields and users to search/view fields.

## Tasks
1. **[Backend] Field Management APIs**
   - Create CRUD APIs for Field management restricted to Owners.
   - Implement logic to generate `field_slots` for a field dynamically.
2. **[Frontend] Owner Dashboard**
   - Build the UI for field creation.
   - Build UI for adding/managing slots for a specific field.
3. **[Frontend] Public Facing Pages**
   - Create public page for searching fields.
   - Implement filtering by location and field type.
