# Phase 1: Foundation & Auth

## Goal
Set up the initial project structure, connect to the database, and implement user authentication with Role-Based Access Control (RBAC).

## Tasks
1. **[Backend] Initialize Project**
   - Setup Node.js/Express repository.
   - Configure environment variables.
2. **[DB] Supabase Schema**
   - Design and apply `users` and `fields` schemas using Supabase and Prisma.
3. **[Backend] Authentication**
   - Implement login and registration API.
   - Setup JWT validation and RBAC middlewares.
4. **[Frontend] Initialize Project**
   - Setup Vite with React.
   - Install Tailwind CSS.
   - Configure React Router.
5. **[Frontend] Auth Pages**
   - Build Login and Register forms.
   - Integrate authentication state via `AuthContext`.
